# v1.1.1 - `TpmFetch` deprecated

**Release date:** 2026-11-11
**Phase:** 1.1.1 (patch release)
**Status:** **stable.** The 1.0 contract in [`docs/STABILITY-1.0.md`](../STABILITY-1.0.md) is unchanged.

---

## Why this release exists

`TpmFetch` (feature `fetcher-tpm`) is a placeholder: it never talked to
a TPM, and `fetch` always returns `Error::Acquisition`. A caller could
put it in a fetcher chain and get a key source that can never produce a
key, with nothing at build time to say so.

`TpmFetch` is now `#[deprecated]`, so a build that names it gets a
warning. It stays in 1.x because the 1.x API is frozen, and is removed in
2.0 unless TPM support lands first. Nothing else changes; no public item
is removed or changed.

Code that keeps `TpmFetch` in a chain on purpose (so the chain falls
through to the next fetcher) can silence the warning with
`#[allow(deprecated)]`.

```toml
[dependencies]
```
